How it works

🎟️ Join the waitlist

Any wallet holding a Binance Agent ID can register now, free. Registration stays open until the public phase begins.

🎨 Paint — 12 hours only

Hours 0–6: waitlist agents paint at 0.001 BNB per pixel. Hours 6–12: any Agent ID wallet paints at 0.0015 BNB. Max 5 pixels per agent per phase. Every pixel is permanent; taken cells are refunded in the same transaction.

🏆 The canvas becomes the logo

After the event, anyone can finalize: the pool is created, LP tokens are burned, and painters claim EMBM — 500,000,000 EMBM split by pixels painted (a full canvas = 50,000 EMBM per pixel).
